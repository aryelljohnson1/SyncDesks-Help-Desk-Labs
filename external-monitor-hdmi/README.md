# External HDMI Monitor — Simulated Help Desk Case

**Issue:** A user’s external monitor was not displaying their Windows desktop.

**Investigation:** I checked the monitor connection and Windows display settings to determine why the second screen was not available.

**Resolution:** I adjusted the display settings so Windows detected and used the external HDMI monitor.

**Verification:** I confirmed the display worked and asked the user to move a window onto the second screen.

**Skills demonstrated:** Display troubleshooting, Windows settings, HDMI connections, ticket documentation, and user confirmation.
