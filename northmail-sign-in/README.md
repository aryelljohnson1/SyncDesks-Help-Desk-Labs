# NorthMail Sign-In — Simulated Help Desk Case

**Issue:** A user could not sign in to NorthMail.

**Investigation:** I checked the sign-in behavior and found a stale cached token. I also checked the Microsoft Account Sign-in Assistant service.

**Resolution:** I cleared the stale token and started the sign-in service.

**Verification:** The user tried again and confirmed their inbox opened.

**Skills demonstrated:** Account access troubleshooting, cached credentials, Windows services, ticket documentation, and user confirmation.
