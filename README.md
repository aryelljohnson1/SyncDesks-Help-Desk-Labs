# SyncDesks Help Desk Labs

Three simulated help desk cases I completed and documented in 2026. Each case covers the reported issue, troubleshooting steps, resolution, and verification with the user.

## Cases

1. **Windows internet outage:** Identified a 169.254.x.x address, renewed DHCP, and verified the IP address, gateway, DNS, ping, and browser access.
2. **External HDMI monitor:** Checked display settings, restored the second screen, and confirmed the user could move a window onto it.
3. **NorthMail sign-in:** Cleared a stale cached token, started the Microsoft Account Sign-in Assistant, and verified the inbox opened.

**Environment:** Simulated help desk tickets and workstations.
